## 1. What it is

OHM-Synapse is a sovereign cognitive operating system under development.
An "epistemic digital twin": an agent that **never asserts without grounding**,
**prefers to abstain rather than hallucinate**, and runs **locally, P2P encrypted, without vendor lock-in**.

It is not a chatbot. It is an architecture of memory + reasoning + sovereignty.

---

## 2. Why it exists

Three problems current LLMs do not solve:

1. **Structural hallucination** — the model does not know that it does not know.
2. **Amnesia between sessions** — every chat starts from zero.
3. **Vendor dependence** — the user's brain lives on someone else's server.

OHM-Synapse treats each as an engineering problem, not a prompt problem.
